# 灵信 LingXin

类似微信的即时通讯 Web 演示应用。

## 功能

- 登录进入演示账号
- 微信式会话列表（置顶、未读角标、搜索）
- 私聊 / 群聊，发送消息后自动回复
- 通讯录，点击联系人进入聊天
- 朋友圈：浏览、点赞、评论、发表动态
- 「我」页面与退出登录

## 启动

```bash
cd lingxin
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。

## 技术栈

React + TypeScript + Vite + Framer Motion + Lucide
